# Project context

Vault Prospector is a local-first Windows desktop application for discovering and searching Azure
Key Vault metadata across explicitly connected identities. It retrieves a secret value only after
an explicit user action and fresh Windows verification. The public release is an unsigned Preview
for non-production evaluation; unreleased source contains later roadmap phases.

The project prioritizes encryption, isolated identity context, least disclosure, read-only Azure
behavior, redacted diagnostics, explicit policy, accessibility, and evidence-backed release claims.
Azure remains the source of truth. The app does not send project-controlled telemetry.

Canonical product sources are the project charter, `pmo/backlog.md`, `pmo/plan.md`, the
release-readiness matrix, and `.ai/state/GOAL.md`.
