# Vault Prospector 0.2.0-preview.5

`0.2.0-preview.5` is the current Windows x64 non-production evaluation release. It replaces
withdrawn `0.2.0-preview.4`, whose clean first-run Identity Type selector could render a null
conversion error.

## Corrected

- Preserve the selected identity type while enterprise policy is applied.
- Default a clean first-run profile to `InteractiveUser` without requiring a dropdown workaround.
- Retain the Preview.4 HWND-bound Windows verification correction.

The exact public MSI passed a clean Windows 11 test with Windows Hello, `InteractiveUser` selected,
and no prior `InvalidCastException`.

## Download and trust

Download the exact MSI, its `.sha256` file, and its `.sigstore.json` bundle from the
[public release](https://github.com/Hybrid-Solutions-Cloud/vault-prospector-releases/releases/tag/v0.2.0-preview.5).
The direct installer is intentionally unsigned and displays **Unknown Publisher**. Verify its
SHA-256 before installation:

```text
FDFF5FB0458012B558E1B0C51AA6BBD6A39FD3BBCFABBC44870795075C8B567B
```

accessibility and usability evidence, live identity/provider matrices, trusted Microsoft Store
distribution, and the other General Availability gates remain open.
