# Vault Prospector 0.2.0-preview.4

`0.2.0-preview.4` is the current Windows x64 non-production evaluation release. It replaces
withdrawn `0.2.0-preview.3`, whose local unlock path called the wrong Windows verification API for
an unpackaged desktop application.

## Corrected

- Bind the Windows verification request to the real application window through
  `UserConsentVerifierInterop`.
- Keep the application locked when no valid window handle or verification device is available.
- Explain when Windows reports verification unavailable in a Remote Desktop session and direct the
  user to reconnect through the local Windows or Hyper-V console.

## Download and trust

Download the exact MSI, its `.sha256` file, and its `.sigstore.json` bundle from the
[public release](https://github.com/Hybrid-Solutions-Cloud/vault-prospector-releases/releases/tag/v0.2.0-preview.4).
The direct installer is intentionally unsigned and displays **Unknown Publisher**. Verify its
SHA-256 before installation:

```text
8CC1E6CCC9557593DEBB72DD05F3F57F738FFF5C97981B7A2EB238BD156933AE
```

The release is for voluntary non-production evaluation. Local-console Windows Hello
success/cancellation, independent reviews, live identity/provider matrices, trusted Microsoft
Store distribution, and the other General Availability gates remain open.
