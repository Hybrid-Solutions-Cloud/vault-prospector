# Vault Prospector 0.3.0-preview.19

`0.3.0-preview.19` was an unsigned Windows x64 manual-test Preview and is superseded by
[`0.3.0-preview.20`](0.3.0-preview.20.md).

## Fixed

- Search now reports the complete number of matching indexed objects instead of presenting the
  first 250-row page as the total.
- Search results can be loaded in additional 250-row pages with stable ordering and no overlap.
- Enterprise allowed-tenant policy is applied before totals and pages are calculated.

## Added

- Connections now offers both **Sync selected** and **Sync all identities**.
- All-identity sync processes every enabled, ready, policy-allowed connection, isolates failures
  by identity, and reports skipped identities.
- Synchronization error retries retain the identity that owns the failed operation.

## Download and trust

Download packages, adjacent checksums, and Sigstore bundles from the
[public binary-only release](https://github.com/Hybrid-Solutions-Cloud/vault-prospector-releases/releases/tag/v0.3.0-preview.19).
The direct installer is intentionally unsigned and displays **Unknown Publisher**. Verify the exact
download against its adjacent SHA-256 file and keyless Sigstore bundle before installation.

## Validation boundary

The governed build passed 498/498 tests with zero warnings or errors and no known vulnerable NuGet
packages. Browser tests passed 6/6, all three local exact-MSI validators passed, and protected PR,
exact-main, and immutable-tag workflows passed. Fresh downloads of all five public packages matched
their adjacent checksums and passed keyless Sigstore verification.

The exact public Preview 19 MSI has not yet been installed and exercised against the product
owner's live multi-identity Azure inventory. Upgrade behavior, totals above 250, and selected/all
identity synchronization remain the explicit manual-test objectives; no installed/live pass is
claimed yet.
