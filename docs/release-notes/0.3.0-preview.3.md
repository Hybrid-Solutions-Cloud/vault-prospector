# Vault Prospector 0.3.0-preview.3

`0.3.0-preview.3` was a Windows x64 non-production evaluation release that replaced withdrawn
`0.3.0-preview.2`. It is superseded by
[`0.3.0-preview.5`](0.3.0-preview.5.md).

## Included

- Persistent Atlas workspace and grouped navigation context from startup onward.
- Explicit secure unlock with no automatic Windows credential prompt.
- Policy-controlled current-account verification for supported Remote Desktop and AVD sessions.
- Multi-identity, synchronization, search, reveal, workspace, browser-fill, administration,
  diagnostics/support, and update workflows introduced during the Atlas redesign.
- Fail-closed preservation and explicit archive recovery for unreadable encrypted local data.

## Download and trust

Download the exact MSI, its `.sha256` file, and its `.sigstore.json` bundle from the
[public release](https://github.com/Hybrid-Solutions-Cloud/vault-prospector-releases/releases/tag/v0.3.0-preview.3).
The direct installer is intentionally unsigned and displays **Unknown Publisher**. Verify:

```text
778456E2B8BEBE595092961BCA19221F1E034AD31911E57D332EAA01FAD72C78
```

This release is for voluntary non-production evaluation. Independent review, complete
accessibility and usability evidence, live identity/provider matrices, trusted Microsoft Store
distribution, and the other General Availability gates remain open.
