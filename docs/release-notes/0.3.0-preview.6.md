# Vault Prospector 0.3.0-preview.6

`0.3.0-preview.6` is the current unsigned Windows x64 manual-test Preview. It replaces
`0.3.0-preview.5` and contains the completed current Windows production-code backlog.

## Included

- Approved C · Atlas installation, setup, search, administration, browser-fill, support, and
  settings workflows.
- Readable installed result text, selectors, code/configuration boxes, and independently scrolling
  Find Secrets results.
- Correct upgraded first-run progression and connected-identity enable, removal, workload
  discovery, and synchronized context behavior.
- Guided browser-extension installation and native-host detection.
- Approved application-header and installer branding.
- Trusted update checks, privacy-safe support bundles, remote-session verification, reveal grace,
  and governed Azure Key Vault mutation controls.

## Validation boundary

The HCS exact-main and immutable-tag workflows passed the full Windows source suite, performance,
packaging, installer/browser contracts, clean installer lifecycle, readiness, SBOM, Sigstore, and
publication checks. Product-owner installed workflow testing remains pending.

This Preview is for voluntary non-production evaluation. Direct Windows binaries remain unsigned.
Independent security, complete live Azure, accessibility/usability, and Microsoft Store signing
gates remain open before GA. CyberArk is post-GA roadmap work, and mobile is a separate roadmap.
