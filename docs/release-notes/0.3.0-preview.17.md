# Vault Prospector 0.3.0-preview.17

`0.3.0-preview.17` is the current unsigned Windows x64 manual-test Preview.

## Included

- Routine foreground, background, and failed-scope synchronization remains noninteractive; failed
  metadata operations are grouped into named tenant, subscription, or vault targets.
- Clipboard Copy uses the current unlocked application session by default. A Settings option can
  require fresh Windows verification for every copy; enterprise clipboard policy and automatic
  clearing remain enforced. Reveal keeps its separate verification policy.
- Workspaces have a self-contained editor that lists included resources and provides visible
  identity, tenant, subscription, and vault pickers plus removal.
- Managed-identity and service-principal discovery use the tenant and connected administrator
  account represented by the selected Administration subscription.
- About links to the public user guide, roadmap, changelog, release verification guide, and release
  history.
