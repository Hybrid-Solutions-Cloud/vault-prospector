## Installer and signing boundary

The exact release workflow validated MSI upgrade scheduling, shortcut/icon contracts, MSIX
structure, browser-host installation, and package-manager manifests. The clean Windows 11
install/upgrade/repair/downgrade/uninstall gate remains supported by the exact public
`0.2.0-preview.1` 27/27 lifecycle record; this evidence does not misrepresent that lifecycle as a
new `0.2.0-preview.3` clean-guest run.

Direct MSI, MSIX, and ZIP packages are intentionally unsigned and display **Unknown Publisher**.
Checksums, SBOM, and Sigstore provenance protect direct-download integrity but are not Windows
publisher trust. The no-cost trusted Windows path remains Microsoft Store ingestion and
Microsoft-signed MSIX; Store certification, install, and upgrade evidence remain open.

## Scope and residual risk

CyberArk and native mobile are separate future-roadmap releases and do not block this Windows
Preview or Windows GA. This Preview remains non-production because independent security,
accessibility, usability, live Windows Hello/Entra/Azure matrices, governed enterprise deployment,
legal/privacy approval, operational exercises, and Microsoft Store acceptance remain open in the
[release-readiness matrix](../product/release-readiness.md).
