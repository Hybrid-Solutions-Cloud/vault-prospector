# 0.1.0-preview.1 Release Evidence

This record captures the reproducible gates for the first Vault Prospector Windows preview. Final GitHub workflow and asset links are authoritative after the tag is published.

## Local release gates

The release candidate must pass all of the following from a cleanly restored dependency graph:

- Windows PowerShell build, all unit and integration tests, and coverage collection through `scripts/Build.ps1`.
- Windows `win-x64` self-contained packaging through `scripts/Package.ps1`.
- HCS Tier 1 Ubuntu WSL locked restore, formatting verification, cross-compilation, and all cross-platform tests.
- NuGet known-vulnerability audit, Markdown-link verification, YAML parsing, secret-pattern scan, and `git diff --check`.
- Packaged executable startup and responsive main-window verification on Windows.

Final pre-publication results on 2026-07-16:

- Windows .NET SDK 9.0.316: zero-warning build; 22 of 22 tests passed.
- HCS Tier 1 Ubuntu WSL .NET SDK 9.0.315: zero-warning cross-build; 22 of 22 tests passed.
- Windows package: self-contained `win-x64` archive produced; zero PDB files; canonical lock files unchanged.

## Security evidence

- SQLCipher database tests verify that the SQLite header and indexed plaintext are absent from the stored file.
- Offline-value tests verify AES-GCM round trips, expiration, metadata-fingerprint invalidation, and scoped purge behavior.
- Authentication tests verify the Azure Resource Manager audience, per-identity client binding, atomic Windows Hello-gated caching, and fail-closed consent handling.
- Diagnostics tests verify allowlisted fields and pseudonymized identifiers without exception-message disclosure.

## Environment-bound validation

The automated suite does not authenticate against a live Microsoft Entra tenant or read a live Azure Key Vault. Those behaviors require an evaluator-owned public-client registration, tenant policy, and Azure RBAC/data-plane permissions. The preview documentation provides the required setup and clearly identifies this boundary.
