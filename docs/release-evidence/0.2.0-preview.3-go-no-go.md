## Accepted Preview risks

- Direct Windows binaries are not Authenticode-signed and display **Unknown Publisher**.
- Independent security, legal/privacy, accessibility, and representative usability approvals are
  incomplete.
- Complete live Windows Hello, Entra, Azure identity, permission, and enterprise-policy matrices
  are incomplete.
- Microsoft Store certification and Microsoft-signed install/upgrade evidence remain open.
- WinGet and Chocolatey catalog acceptance remain external post-publication work.

CyberArk and native mobile are separate future-roadmap releases. Their tenant, device, signing,
and store evidence is not an accepted Windows-release risk and does not block this decision.

These risks are accepted only for voluntary non-production evaluation. They do not satisfy GA.

## Rollback triggers

Withdraw this version if artifact identity differs from the recorded hashes/bundles, the installer
corrupts or removes retained state, protected values or credentials appear in diagnostics or
artifacts, required verification can be bypassed, or a critical/high security defect is confirmed.

## Remaining promotion gates

The [release-readiness matrix](../product/release-readiness.md) remains authoritative. No stable or
GA promotion is permitted until its independent review, live identity/provider, accessibility and
usability, enterprise, operational, legal/privacy, and free Microsoft Store signing gates pass
with exact-candidate evidence.
