while applying enterprise policy, preventing the clean first-run selector from receiving a

replacement; its tag and assets remain unchanged for auditability.

## Residual risk

This remains a non-production Preview. Independent security and accessibility review,
representative usability, live Microsoft Entra and Azure matrices, governed enterprise
deployment, legal/privacy approval, operational exercises, and Microsoft Store acceptance remain
open in the [release-readiness matrix](../product/release-readiness.md). CyberArk and native mobile
remain separate future-roadmap releases.
