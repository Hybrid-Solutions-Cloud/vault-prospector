## Rollback triggers

Withdraw the release immediately if any of the following is observed:

- encryption, authentication, Windows Hello, or read-only enforcement can be bypassed;
- a secret/token/value appears in logs, diagnostics, release assets, or project telemetry;
- install/upgrade removes the prior usable version or retained local state after failure;
- published hashes, provenance, or source commit do not match downloaded assets;
- a critical/high security issue is confirmed without an effective containment;
- widespread startup, authentication, synchronization, or uninstall failure prevents evaluation.

Never replace assets under the same tag. Publish withdrawal guidance, preserve evidence, and issue
a new version after remediation.
