## Replacement rationale

`0.3.0-preview.3` replaces withdrawn `0.3.0-preview.2`, completes the approved C · Atlas startup
and secure-unlock hierarchy, keeps the
application locked until explicit verification, and provides a policy-controlled current-account
credential prompt in supported Remote Desktop and AVD sessions. The exact public MSI installed
successfully and rendered the corrected startup in the retained Windows 11 acceptance guest.

## Accepted Preview risks

- Direct Windows binaries are not Authenticode-signed and display **Unknown Publisher**.
- Complete keyboard, assistive-technology, representative-user, and independent review remain
  open.
- Complete live Microsoft Entra, Azure permission, isolated-error, browser, enterprise-policy,
  and workload-identity matrices remain open.
- Microsoft Store certification and Microsoft-signed install/upgrade evidence remain open.
- WinGet and Chocolatey catalog acceptance remain external post-publication work.

CyberArk and native mobile remain separate future-roadmap products. These risks are accepted only
for voluntary non-production evaluation and do not satisfy GA.

## Rollback triggers

Withdraw this version if required verification can be bypassed, the supported RDP prompt fails,
artifact identity differs from the recorded hashes or bundles, the installer removes retained
state, protected values or credentials appear in diagnostics or artifacts, or a critical/high
security defect is confirmed.

## Remaining promotion gates

The [release-readiness matrix](../product/release-readiness.md) remains authoritative. No stable or
GA promotion is permitted until its independent review, live identity/provider, accessibility and
usability, enterprise, operational, legal/privacy, and Microsoft Store signing gates pass with
exact-candidate evidence.
