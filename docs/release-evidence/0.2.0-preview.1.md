## Exact public MSI lifecycle

The anonymously downloadable public MSI was exercised on the isolated
`vp-win11-preview-test` Windows 11 Enterprise Evaluation 25H2 guest
(`Microsoft Windows NT 10.0.26200.0`) from `2026-07-24T21:03:59Z` through
`2026-07-24T21:05:23Z`.

All 27 gates passed:

- administrator context and clean start;
- exact previous/current checksums, stable UpgradeCode, distinct ProductCodes, and increasing MSI
  ProductVersion (`0.1.101` to `0.2.1`);
- installation of immutable `0.1.1-preview.1`;
- deterministic post-`InstallFiles` failure returning `1603`, with exact registration,
  executable/runtime configuration, shortcut, and retained-state rollback;
- successful upgrade to `0.2.0-preview.1`;
- forced repair of a deliberately changed packaged file;
- rejection of the older MSI while preserving `0.2.1`; and
- uninstall registration/file/shortcut cleanup while preserving LocalApplicationData state.

The structured result is
[`0.2.0-preview.1-installer-lifecycle.json`](0.2.0-preview.1-installer-lifecycle.json), SHA-256
`7F4B55D13A53D3202ACD473944C7A002705ACDDF38B837947CD9ECFD7783568F`.

The validation used a reversible Hyper-V checkpoint and a one-time LocalSystem boot harness
because the disposable guest credential from the earlier run was no longer retained. After
collecting the result, the checkpoint was restored and removed. Final host inspection confirmed:
VM off, zero Vault Prospector registrations, no `C:\VPTest`, zero checkpoints, and Guest Service
Interface disabled.
