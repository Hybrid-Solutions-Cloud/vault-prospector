## Replacement rationale

On a clean profile, `0.2.0-preview.4` cleared the bound identity-type collection while applying
enterprise policy. Avalonia propagated the transient null selection into a non-nullable enum,
causing the first-run selector to render an `InvalidCastException`.

`0.2.0-preview.5` synchronizes the collection incrementally and preserves the default
`InteractiveUser` selection. Automated regression coverage rejects collection resets. A dedicated
Windows 11 Hyper-V guest installed the exact public MSI, completed Windows Hello, and displayed the
first-run Identities workflow with `InteractiveUser` selected and no conversion error.

## Accepted Preview risks

- Direct Windows binaries are not Authenticode-signed and display **Unknown Publisher**.
- Windows verification may be unavailable through Remote Desktop; users must reconnect through
  the local Windows or Hyper-V console. The application remains locked in the unavailable session.
- Independent security, legal/privacy, accessibility, and representative usability approvals are
  incomplete.
- Complete live Microsoft Entra, Azure identity, permission, and enterprise-policy matrices are
  incomplete.
- Microsoft Store certification and Microsoft-signed install/upgrade evidence remain open.
- WinGet and Chocolatey catalog acceptance remain external post-publication work.

CyberArk and native mobile are separate future-roadmap releases and do not block this Windows
Preview decision. These risks are accepted only for voluntary non-production evaluation and do
not satisfy GA.

## Rollback triggers

Withdraw this version if required verification can be bypassed, the HWND-bound request fails on a
supported local console, the first-run identity selection again becomes invalid, artifact identity
differs from the recorded hashes or bundles, the installer corrupts or removes retained state,
protected values or credentials appear in diagnostics or artifacts, or a critical/high security
defect is confirmed.

## Remaining promotion gates

The [release-readiness matrix](../product/release-readiness.md) remains authoritative. No stable or
GA promotion is permitted until its independent review, local-console and live identity/provider,
accessibility and usability, enterprise, operational, legal/privacy, and free Microsoft Store
signing gates pass with exact-candidate evidence.
