# Research Spikes

Research spikes reduce architectural uncertainty before implementation.

Each spike should produce:

- A written question.
- A small proof of concept where useful.
- Evidence.
- Security implications.
- A recommendation.
- A clear outcome: accept, reject, or continue research.
